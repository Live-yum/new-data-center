# IoT 设备看板微前端

## 入口与运行

继续使用真实 qiankun 3 `web-ele → web-data-center` 生命周期及会话 bridge，未使用 iframe。原部门目录、字典与总览仍可访问。新增 `/devices`、`/dashboards`、`/widgets`、`/history`、`/downloads`、`/sources` 和五个 `/process-*` 子路由，由宿主 `?view=` 同步；标题区压缩为导航与操作栏。

前端工作区运行：

```bash
pnpm install --frozen-lockfile
pnpm dev:micro-demo             # 无后端演示宿主 5174 + 子应用 5175
pnpm build:micro-demo
pnpm preview:micro-demo         # 构建产物复验
pnpm check:micro
pnpm exec vitest run apps/web-data-center/src/iot apps/web-micro-demo/src/demo-iot.test.ts
```

正式管理端使用既有 `pnpm dev:ele` 与 `pnpm dev:data-center`，通过原登录、租户、权限拦截器调用 `/admin-api/iot`。桥接函数限定方法与路径，不向子应用发送 token、实时库密码或任意 HTTP 代理能力。独立打开子应用无 bridge 时明确显示未连接，不伪造业务数据。

## 可操作流程

1. **设备与测点**：建立基础设备（名称、编码），将统一指标键映射至该设备真实紫金桥点名及单位；修改的是平台元数据，不修改现场设备配置。支持添加、删除映射并整体保存。未提供全量采集源/驱动组态。
2. **设备看板**：创建空白看板或模板副本；进入编辑，从组件图库添加组件，配置指标与绑定模式，保存看板。名称、组件、绑定、布局均由后端持久化，重载后恢复。
3. **布局**：桌面采用 12 列网格，左上拖动手柄移动、右下手柄缩放；手柄聚焦后支持方向键。拖拽/缩放碰撞时相邻组件向下让位，不遮盖内容。移动端按组件顺序单列展示，禁用拖拽缩放。保存为显式操作，没有假自动保存。
4. **绑定**：`currentDevice` 跟随顶部设备选择；`fixed` 只读第一个指定设备；`multiple` 使用固定设备集合，不随顶部切换。统一指标缺失时明确提示，绝不补零。不同单位独立分图，不自动换算。
5. **模板**：保存为当前设备模板要求所有组件均使用 `currentDevice`；固定/多设备看板先显式修改绑定后方可保存模板。使用模板会创建副本，不修改模板本体。
6. **历史**：选择设备集合、指标、本地起止时间，提交时转换为 ISO UTC；支持取消请求，迟到响应不回填。RAW 按指定间隔采样（并非原始全量记录）；AVG/MIN/MAX/LAST 是整个请求时间窗的采样结果统计为一个值，**不是等间隔分桶曲线**。
7. **导出**：从历史条件创建服务端下载任务；列表轮询，运行任务可取消，只有 SUCCEEDED 可下载 CSV。失败/取消/过期任务不可下载。CSV 与查询使用相同采样/窗口统计口径，通过鉴权 Blob 请求，不公开私有下载 URL。

## 组件与数据边界

- 趋势折线、对比柱状、仪表、数值卡、状态时间轴、数据表、图片测点热点共七种组件。
- 看板趋势默认60秒间隔采样，长窗口/多设备时自动增大间隔，以满足10000采样点上限。历史页面可显式设置采样间隔（至少1秒）、最多7天。
- SVG 渲染，无新增图表依赖。折线缺失/无效值形成断点；状态时间轴按真实采样间隔展示，不将末值无限外推。
- 数值卡/仪表/数据表/图片只读取最新实时 RAW 值，编辑器不提供历史窗口/聚合；状态时间轴仅 RAW 间隔状态；折线/柱状允许窗口统计。
- 图表使用查询结果单位而非任意替换单位字符串；质量使用服务端值，UNKNOWN 不冒充 GOOD。DEMO 仅存在于演示宿主。
- 图片仅允许站内 `/` 路径（非 `//`、无反斜杠），禁用外部 URL/data/javascript。两宿主提供内置 `/images/iot-boiler.svg`。热点支持位置、标签与指标，点击只读历史，不发送设备控制。图片仅支持当前设备/固定单设备；设备集合比较使用折线、柱状或表格。
- 尚无图片上传、阈值告警编辑、自动单位换算、设备控制、生产部署或真实设备接入凭据；UI不伪装支持这些能力。

## 会话、并发与生命周期

共享类型位于 `packages/micro-apps/src/iot.ts`。正式 bridge 使用原 `requestClient`，每次请求绑定调用信号与宿主 lifetime；用户、租户变化使旧 lifetime 失效。子应用重新初始化时取消所有读请求、历史查询和轮询，清空旧租户状态；旧响应即使忽略 AbortSignal 也不会回填。卸载取消请求、定时器、指针监听。

保存/切换/删除请求期间整个看板编辑区禁用，事件处理也检查 busy，避免迟到保存覆盖后续草稿。正式请求拒绝对象经 `normalizeIotError` 归一化，仅提取业务码/消息，业务码 `1070000409` 显式触发冲突恢复 UI。

看板更新携带 `version`；冲突保留本地草稿并提示加载最新版本，不自动覆盖远端。演示实现模拟相同版本约束，使用 `localStorage` 按租户隔离；所有写入先完成可取消延时，成功后才持久化。演示数据与正式后端路径完全隔离，不作为正式请求失败的回退。

## 验证范围

单元与组件逻辑测试覆盖：绑定解析、UTC窗口、grid边界、无效/缺失采样、独立单位、图片URL、热点、演示持久化与冲突、模板约束、导出状态、取消请求不落盘、旧租户迟到结果隔离、卸载轮询清理、历史取消与路由离开、看板冲突保留草稿。

浏览器脚本 `scripts/test-iot-demo.mjs` 负责实际 qiankun 页面操作回归。运行依赖可用本地浏览器与端口；测试脚本存在或构建通过不等于浏览器已运行。正式后端/真实紫金桥联调与浏览器结果，以本次根报告、CI记录为准。

## 生产工艺页面与紫金桥接入

正式管理端导航「生产工艺」「紫金桥数据源」使用生产 bridge 与 `/admin-api/iot/process-pages`；不使用演示宿主、`demoOilgasQuery`、固定示例设备 ID 或随机数值。`context.dataSource` 必须为 `platform`，并具备生产页面 API。五种页面类型均可建立多个命名实例：

| 页面类型 | 子路由 / 宿主 `view` 参数 | 初始布局位置 |
| --- | --- | --- |
| 陆地油气水分离 | `/process-separation` / `process-separation` | 缓冲、分离、转输、采出水 |
| 天然气处理 | `/process-gas` / `process-gas` | 入口分离、脱水、压缩、出口缓冲 |
| 储罐外输 | `/process-storage` / `process-storage` | 两个储罐、两台外输泵 |
| 泵站公用工程 | `/process-utilities` / `process-utilities` | 循环水罐、双泵、回水缓冲 |
| 海上平台总览 | `/process-offshore` / `process-offshore` | 分离、缓冲、外输、压缩模块 |

这些是**功能布局模板，不是已知现场工程图或 P&ID**。目前每种布局四个位置，不能任意绘制/改接管线；图中位置名称只作配置提示，绑定后显示真实设备名称、编码。图标位置编号只在浏览器选中定位时使用，查询永远使用用户选定的真实设备 ID。没有设备控制或写值能力。

### 从空白绑定到真实只读页面

1. 在「紫金桥数据源」（`/sources`）查看后端统一管理的数据源状态：`DISABLED`、`NOT_CONFIGURED` 或 `CONFIGURED`。**已配置不等于已连接或验收通过**；状态接口不做自动连接探测，也不返回 URL、密码或令牌。实际连接由管理员通过部署侧 `yudao.realdb` 配置及现有认证流程启用，不在浏览器创建或编辑凭据。
2. 在「设备与测点」创建真实设备，并维护指标键 → 该设备紫金桥点名/单位的映射。生产页面不会猜点名或假定设备间指标相同。
3. 选择布局类型，点击「新建页面」。填写名称、说明，逐位置选择真实设备、多选已存在的指标映射，再指定图上主测点。未绑定位置可保留空白。设备切换会清除旧设备的指标选项，不把旧测点带到新设备。
4. 显式保存后，页面名称、布局类型、四个位置的设备/指标绑定、刷新间隔、陈旧阈值及版本保存至业务数据库；重新加载读取服务端配置。刷新间隔 5–300 秒，陈旧阈值不小于刷新间隔且不超过 3600 秒；每位置最多20个指标，总计最多50个。重复绑定同一设备会合并去重，再按每请求最多20指标拆批，不生成设备×指标的无效交叉积。
5. 图中位置/下拉选择联动真实测点、历史趋势与采样表。实时按配置轮询，历史在条件变化或显式查询时读取。历史可选30分钟/1小时/6小时/24小时、采样间隔及数值/状态展示；RAW是间隔采样，不是全量原始记录。不同指标保持结果返回的单位，不自动换算。
6. 「下载当前查询窗口」复用**最近一次成功历史查询的相同 UTC 起止时间、设备、指标、间隔**创建服务端任务，不在点击时移动窗口。到「下载任务」等待实际成功后下载；创建成功不代表导出完成。
7. 删除采用页面内二次确认和版本校验，只删除平台页面配置，不删除设备和紫金桥测点。版本冲突保留本地草稿；显式确认放弃草稿才能加载最新版本，不自动覆盖远端。

### 值、质量与时间边界

- 生产结果必须为 `source: REALDB`；非 REALDB 来源或 `DEMO` 质量直接拒绝，失败不会切换至演示数据。
- 未绑定、映射缺失、读取失败、读取中、缺测、质量不良、陈旧、未知质量分别呈现；缺失/BAD/无效/陈旧值不补零、不显示为当前健康数值。一次设备读取失败只清除该设备的旧值，不影响其他设备。
- 保留原始质量，不把 `UNKNOWN` 推断为 `GOOD`。UNKNOWN的实际值如能读取可显示，但明确标注未知，不推断安全运行状态。
- 点值附带 `timeSource: DEVICE | RECEIVED`。只有设备提供的有效采样时间 `DEVICE` 才能判定新鲜/陈旧。后端补记接收时刻 `RECEIVED` 显示「接收时间 / 采集时间未知」；旧服务未提供来源也按未知处理，不能把请求成功时间当采集时间。
- 历史曲线不把接收时间/来源未知时间当采样时间；这些记录仅在采样表展示来源，曲线留空。最新请求成功时间单独注明，不能代表全部测点质量正常。
- 手机工艺图独立横向滚动，选中位置自动定位；页面主体不横向溢出。页顶仅紧凑导航/操作栏，没有占据内容区的大标题。

### 生命周期与验证

生产页面编辑、保存、切换、版本恢复、历史取消分别受忙碌状态和请求生命周期保护。编辑时暂停读取并清空旧值；切换页面/设备/指标取消对应读取，迟到响应不会污染新视图；用户/租户/bridge变化强制清空旧会话数据。离开子路由和离开宿主页面均注册未保存草稿确认，拒绝后恢复宿主真实路由；浏览器关闭/刷新有标准未保存提示。卸载清理轮询、时钟、请求和离开钩子。

生产模型/组件单测使用显式契约替身，只证明界面状态与请求约束，不证明现场紫金桥已接通。生产链路回归使用真实 IoT HTTP、数据库、正式 bridge 和真实 qiankun 挂载，上游替身仍必须明确标为契约测试。最终执行结果见本次测试记录；现场版本/账号/网络/时区/权限实机验收仍需独立完成。

## 陆地油气与海上平台演示

演示宿主进入「油气演示」，可在以下五个页面切换；没有页顶大标题，内容区以工艺图、设备测点和趋势为主：

| 页面 | 宿主地址（开发/预览） | 示例设备 |
| --- | --- | --- |
| 陆地油气水分离 | `http://127.0.0.1:5174/#/data-center?view=demo-separation` | 缓冲罐、三相分离器、转输泵 |
| 天然气处理 | `http://127.0.0.1:5174/#/data-center?view=demo-gas` | 分离器、脱水塔、压缩机 |
| 储罐外输 | `http://127.0.0.1:5174/#/data-center?view=demo-storage` | 储罐、外输泵 |
| 泵站公用工程 | `http://127.0.0.1:5174/#/data-center?view=demo-utilities` | 循环水泵、缓冲罐、空压机 |
| 海上平台总览 | `http://127.0.0.1:5174/#/data-center?view=demo-offshore` | 平台分离、压缩、输送模块 |

手机端工艺图保留900px可读宽度，在独立容器内左右滑动，页面自身不横向溢出；从设备下拉框切换时图内自动定位，桌面保持完整图。

每页4个样例设备。设备可用指标独立声明：储罐提供液位，外输泵不提供液位；切换设备会移除不适用卡片/选项并重置不适用趋势指标，查询拒绝不适用组合，不为其生成数值。点击 SVG 设备（或设备下拉框）切换只读测点与趋势；趋势可切换压力（储罐页为液位）、温度、流量，运行状态单独显示，不把离散状态画成数值曲线。实时样例每5秒读取，趋势为最近30分钟、60秒间隔RAW，样本时间显示浏览器本地时间；第二台设备的历史中间点特意缺测，显示断线而非补零。量级与单位来自场景目录，只作为演示数据，未配置任何现场安全阈值。

- **隔离**：只有 `context.dataSource === 'demo'` 且存在演示专用 `bridge.iot.demoOilgasQuery` 时启用；正式模式手动访问这些路由仅显示不可用说明，不读取或伪造油气数据。接收结果也必须为 `source: DEMO`。
- **数据**：20个只读样例设备由演示宿主提供，不落入旧锅炉 localStorage，不调用正式后端；使用可选的只读 `demoOilgasQuery` 能力（沿用查询参数/结果契约），正式 bridge 不提供它；普通 `devices/mappings/query` 完全不注入场景目录，旧存档即使有同 ID/同指标也不被覆盖，无任意 HTTP 代理或控制接口。原设备/看板/模板/部门/字典仍保留。
- **素材**：工艺管线、阀门、罐、分离器、泵、压缩机和塔器均为本项目原创 SVG。图形只用于只读测点选择，流程为功能示意、非工程设计/非 P&ID，不代表真实现场流程或生产设定。
- **生命周期**：场景/设备/指标/bridge/用户会话/租户切换清空旧数据、取消旧请求并拒绝迟到响应；离开路由/退出卸载取消请求和5秒轮询。读取失败清空旧值并报错，不保留冒充新鲜数据。
- **验收**：`OilgasDemo.test.ts` 覆盖正式模式拒绝、场景/设备/指标切换、旧租户迟到响应、来源检查、路由离开/卸载；`oilgas-demo.test.ts` 覆盖目录、映射、数据时序和缺测。`scripts/test-oilgas-demo.mjs` 在真实 qiankun 页面截图；构建与单测不等于浏览器截图验收。
